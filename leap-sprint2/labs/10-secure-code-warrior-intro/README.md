# Module 10 Lab — Secure Code Warrior Onboarding and First Challenge

## Objectives

By the end of this lab you will have:

- Understood what the Secure Code Warrior platform is and how it's used across the programme
- Completed platform onboarding and account setup
- Completed an introductory challenge in your primary language track (Java)
- Noted any vulnerability categories you found difficult, for discussion in Module 11

## Setup

- A Secure Code Warrior account, provisioned by your trainer for this cohort
- The OWASP Top 10 (2025) categories from Module 09, fresh in mind

## Task sheet

1. **Sign in and complete onboarding**
   Sign in via SSO, complete your profile, and select **Java** as your primary language track.

2. **Explore the platform briefly**
   Before starting a challenge, look at how challenges are organised: by language, by
   vulnerability category, and by difficulty. Note how the platform's category names line up
   (or don't quite line up) with the OWASP Top 10 (2025) names from Module 09, platforms don't
   always use identical wording for the same underlying idea.

3. **Complete the introductory challenge**
   Work through your track's first challenge: read the vulnerable snippet, identify the
   vulnerability category, choose (or write) a fix, and submit.

4. **Complete at least one further challenge**
   Pick a second challenge, ideally in a category you found the *least* confident about in
   Module 09's lab.

5. **Note your difficulties**
   For each challenge you attempted, write down:
   - Which OWASP category it mapped to
   - Whether you got it right first attempt
   - What made it easy or hard to spot

## Acceptance criteria

- Your Secure Code Warrior profile shows onboarding complete and Java selected as your track.
- You've completed at least two challenges, with a note on the outcome of each.
- You have a short written list of which vulnerability categories you found most difficult,
  ready to bring to Module 11.

## Looking ahead to Module 11

Module 11 has you apply everything so far, OWASP recognition (Module 09) and Secure Code
Warrior practice (this module), to remediate a full, realistic vulnerable codebase, using
Copilot critically alongside your own judgement. The categories you found hardest here are
worth paying closest attention to there.

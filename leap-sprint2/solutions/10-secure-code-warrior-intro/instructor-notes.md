# Module 10 Lab — Instructor Notes

This lab has no code solution, it's an onboarding exercise on a third-party platform. These
notes cover facilitation, not a model answer.

## Before the session

- Confirm every delegate has a Secure Code Warrior account provisioned and SSO actually works,
  ideally the day before, account provisioning issues eat lab time fast.
- Confirm the Java track is available and has an introductory challenge live.

## What to watch for during the lab

- Delegates who select the wrong language track out of habit (picking a language from a
  personal project rather than Java, this programme's stack). Correct this early.
- Delegates who solve a challenge by trial-and-error clicking rather than reasoning about the
  vulnerability first, prompt them to name the OWASP category *before* submitting an answer,
  same discipline as Module 09.
- Note which categories the cohort collectively found hardest, this is genuinely useful
  information to carry into how you pace Module 11 and Sprint 8.

## Connecting to Module 11

Ask each delegate (or have them note privately) their weakest category from this lab. Module 11's
remediation codebase should ideally give everyone at least one vulnerability in a category they
personally found difficult here, if you have any control over how Module 11's exercise is
assigned or paired, use this information to do that deliberately rather than at random.

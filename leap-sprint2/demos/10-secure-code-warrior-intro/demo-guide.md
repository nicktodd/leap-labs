# Demo: Module 10 — Secure Code Warrior Introduction

**Duration:** 8 minutes
**Prerequisite:** A Secure Code Warrior account provisioned for the cohort (trainer confirms
SSO access works before the session). Projector access to the platform.

## Part 1: What Secure Code Warrior is (2 min)

Narration: Secure Code Warrior is a hands-on training platform, not another slide deck. It
presents real, short, vulnerable code snippets in your actual language (Java, for this
programme) and asks you to identify and fix the vulnerability yourself, with instant feedback,
scoring, and progression through increasingly varied challenges. Where Module 09 asked "can you
name the category," Secure Code Warrior asks "can you actually fix it, in code, under a bit of
time pressure."

## Part 2: Where it fits across the programme (2 min)

Point at the diagram on the slides: this module is the onboarding, setting up an account and
completing one introductory challenge. Module 11 has you use it (and Copilot, reviewed
critically) to remediate a full vulnerable codebase. Sprint 8's deep dive on Broken Access
Control, Injection, and Authentication Failures leans on it heavily. The Cyber Challenge Mission
Day (Module 13) draws on everything practised here.

## Part 3: Live walkthrough of onboarding (3 min)

Project the platform and walk through, live:

1. Sign in via SSO
2. Complete the profile step, selecting **Java** as the primary language track (matching this
   programme's stack)
3. Open the introductory challenge for that track

## Part 4: One challenge, together (1 min)

Open the first challenge as a class. Read the vulnerable snippet together, ask the room to
name the OWASP category before revealing the platform's own answer, same habit as Module 09.
Don't solve the whole challenge live, leave that for the lab.

## Key message

Secure Code Warrior turns Module 09's pattern recognition into a practised, scored skill. It's
the bridge between "I can spot broken access control in a code review" and "I can reliably fix
it myself, in my own language, under realistic conditions."

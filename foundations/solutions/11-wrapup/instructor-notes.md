# Module 11 Lab - Instructor Notes

This lab has no "solution" in the usual sense, it's a checklist, not an exercise with a single
right answer. These notes cover what "good" looks like for each section, and the most common
gaps to watch for.

## What good looks like

- **Environment**: no surprises expected here if setup was solid; if someone still can't
  open Docker Desktop or sign in to GitHub by this point, that's a priority fix before anything
  else.
- **Agile & Ceremonies**: watch for delegates who can recite the three Scrum roles but can't
  apply INVEST to a real backlog item, that's a sign Module 02 was memorised rather than
  understood.
- **Git & GitHub**: a real commit history and a real, resolved merge conflict are non-negotiable
  here, both were hands-on in Modules 04-05 and shouldn't need reconstructing from memory.
- **PR & Code Review**: a merged PR with a real Conventional Commit title and a genuine review
  comment (not just an approval) is the real signal, watch for delegates who never actually
  left a substantive comment on a partner's work.
- **GenAI**: watch for delegates who used Copilot for code generation this week rather than
  explanation, that's a scope misunderstanding from Module 09 worth correcting now, before
  hands-on Copilot use later in the programme normalises the wrong habit.
- **Team Repo**: this section doubles as a check on Module 10's actual outcome, if a team's
  branching strategy isn't documented with a real reason by now, that's worth flagging to the
  team directly, not just noting.

## Common gaps and quick fixes

| Gap | Likely cause | Quick fix |
|---|---|---|
| Confuses push and pull | Mixed up direction, common early on | Point back to Module 06's local-vs-remote diagram |
| Can't explain fast-forward merge | Skipped or rushed Module 05's mechanics slides | Walk through the diagram again one-on-one |
| PR has no real review comment | Partner approved without actually reading the diff | Have them re-review live, one specific comment minimum |
| Can't apply INVEST to a real item | Module 02 treated as a definitions lecture, not practised | Re-run the readiness judgement on one item together |
| Branching strategy has no stated reason | Copied from the slides rather than discussed as a team | Ask the team to justify it out loud, in their own words |

## Running the session

Fifteen to twenty minutes total: five for the checklist walkthrough as a pair, the rest for
closing gaps. Circulate rather than lecture, this module works best as one-on-one triage.
